# Complete capability index

Every exported function of every package surveyed in `ECOSYSTEM.md`, sorted into
sixteen capability categories. Generated by `ecosystem/make_index.py` from
`ecosystem/atlas.json`; raw enumerations are in `ecosystem/*.tsv`.

Interactive version: `tmp/capability-index.html` (searchable and filterable — `open tmp/capability-index.html`).

**3,556 functions across 34 packages.** Category assignment is curated by hand
for the eleven packages where the distinction carries the argument and by name-pattern rule
elsewhere. *Temporal centrality* counts only time-respecting definitions — a static formula
recomputed per slice is filed under *Static centrality*, Dynet's own included.
