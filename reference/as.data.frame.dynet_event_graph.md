# Tidy tables from an event graph

Tidy tables from an event graph

## Usage

``` r
# S3 method for class 'dynet_event_graph'
as.data.frame(
  x,
  row.names = NULL,
  optional = FALSE,
  what = c("events", "adjacencies"),
  ...
)
```

## Arguments

- x:

  An event graph returned by
  [`event_graph()`](https://pak.dynasite.org/Dynet/reference/event_graph.md).

- row.names:

  Ignored; present for compatibility with the generic.

- optional:

  Ignored; present for compatibility with the generic.

- what:

  `"events"`, the default, returns one row per event; `"adjacencies"`
  returns one row per arc and shared vertex.

- ...:

  Ignored.

## Value

A plain data frame; the columns are listed under
[`event_graph()`](https://pak.dynasite.org/Dynet/reference/event_graph.md).
