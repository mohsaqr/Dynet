# Print time-respecting paths

Print time-respecting paths

## Usage

``` r
# S3 method for class 'dynet_paths'
print(x, n = 12L, ...)
```

## Arguments

- x:

  A `dynet_paths` from
  [`paths()`](https://mohsaqr.github.io/Dynet/reference/paths.md).

- n:

  Number of rows to show.

- ...:

  Ignored.

## Value

`x`, invisibly.
