# Tidy table of time-bin similarity

Tidy table of time-bin similarity

## Usage

``` r
# S3 method for class 'dynet_similarity'
as.data.frame(x, row.names = NULL, optional = FALSE, ...)
```

## Arguments

- x:

  A result from
  [`similarity()`](https://mohsaqr.github.io/Dynet/reference/similarity.md).

- row.names, optional:

  Ignored.

- ...:

  Ignored.

## Value

A plain data frame, one row per ordered pair of time bins.
