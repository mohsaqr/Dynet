# Draw time-bin similarity as a heatmap

Draw time-bin similarity as a heatmap

## Usage

``` r
# S3 method for class 'dynet_similarity'
plot(x, base_size = 12, ...)
```

## Arguments

- x:

  A result from
  [`similarity()`](https://mohsaqr.github.io/Dynet/reference/similarity.md).

- base_size:

  Base text size.

- ...:

  Ignored.

## Value

A `ggplot` object.
