# Coerce a permutation test to a data frame

Coerce a permutation test to a data frame

## Usage

``` r
# S3 method for class 'dynet_significance'
as.data.frame(
  x,
  row.names = NULL,
  optional = FALSE,
  what = c("result", "null"),
  ...
)
```

## Arguments

- x:

  A `dynet_significance` from
  [`significance()`](https://pak.dynasite.org/Dynet/reference/significance.md).

- row.names:

  Passed to the data frame method.

- optional:

  Passed to the data frame method.

- what:

  `"result"`, the default, for one row per tested cell; `"null"` for the
  null distribution, one row per cell and surrogate.

- ...:

  Ignored.

## Value

A base data frame. Under `what = "result"`, the columns
[`significance()`](https://pak.dynasite.org/Dynet/reference/significance.md)
documents. Under `what = "null"`, the key columns of the statistic (such
as `time`, `node`, `measure`), then `replicate` (the surrogate) and
`value` (the statistic on it, `NA` where the surrogate did not produce
the cell).
