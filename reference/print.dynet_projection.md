# Print a time-projected network

Print a time-projected network

## Usage

``` r
# S3 method for class 'dynet_projection'
print(x, ...)
```

## Arguments

- x:

  A projection returned by
  [`projection()`](https://mohsaqr.github.io/Dynet/reference/projection.md).

- ...:

  Ignored.

## Value

`x`, invisibly.
