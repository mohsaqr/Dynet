# Plot a temporal motif census

Plot a temporal motif census

## Usage

``` r
# S3 method for class 'dynet_motifs'
plot(x, ...)
```

## Arguments

- x:

  A `dynet_motifs` result.

- ...:

  Passed to
  [`graphics::barplot()`](https://rdrr.io/r/graphics/barplot.html).

## Value

`x`, invisibly; a bar plot is drawn as a side effect.
