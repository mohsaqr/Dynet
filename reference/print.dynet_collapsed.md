# Print a collapsed temporal network

Print a collapsed temporal network

## Usage

``` r
# S3 method for class 'dynet_collapsed'
print(x, ...)
```

## Arguments

- x:

  A network returned by
  [`collapse_network()`](https://mohsaqr.github.io/Dynet/reference/collapse_network.md).

- ...:

  Ignored.

## Value

`x`, invisibly.
