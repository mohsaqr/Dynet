# Summarise an event graph

Summarise an event graph

## Usage

``` r
# S3 method for class 'dynet_event_graph'
summary(object, ...)
```

## Arguments

- object:

  An event graph returned by
  [`event_graph()`](https://pak.dynasite.org/Dynet/reference/event_graph.md).

- ...:

  Ignored.

## Value

A plain `data.frame`, one row per event: `event`, its start `time`,
`in_degree` (the distinct events it follows), `out_degree` (the distinct
events that follow it), and `mean_wait`, the mean wait before those
successors start. `mean_wait` is `NA` for an event with no successor,
where no wait is defined.
