# Tidy table of a temporal trajectory tree

Tidy table of a temporal trajectory tree

## Usage

``` r
# S3 method for class 'dynet_path_trajectories'
as.data.frame(x, row.names = NULL, optional = FALSE, ...)
```

## Arguments

- x:

  A result from
  [`path_trajectories()`](https://mohsaqr.github.io/Dynet/reference/path_trajectories.md).

- row.names, optional:

  Ignored.

- ...:

  Ignored.

## Value

A plain data frame with one row per tree node.
