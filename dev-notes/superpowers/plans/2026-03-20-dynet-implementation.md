# Dynet Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a standalone R package for temporal network analysis with 100% numerical equivalence against statnet.

**Architecture:** Standalone package, cograph-compatible by structure. `dynet()` constructor builds the object; all `dyn_*` functions are stateless computations. Base R core, igraph in Suggests for snapshot metrics only.

**Tech Stack:** R, base R, ggplot2, igraph (Suggests), testthat

**Spec:** `docs/superpowers/specs/2026-03-20-dynet-design.md`
**Reference code:** `ref-temporal_network.R` (working algorithms), `ref-test-temporal_network.R` (test patterns)

**Column renaming note:** All internal code uses `$start` and `$end`, not `$onset` and `$terminus`. When porting BFS/path algorithms from the reference, change all `edges$onset` → `edges$start` and `edges$terminus` → `edges$end`.

- [ ] **Step 2: Write utils.R — .detect_columns()**

Smart column detection: case-insensitive matching for from/to (`from/to`, `source/target`, `sender/receiver`, `head/tail`), time (`start+end`, `onset+terminus`, `start+duration`, `time`), session (`session`, `group`, `period`). Returns a named list of resolved column names.

- [ ] **Step 3: Write utils.R — .resolve_sessions()**

Takes a dynet object and `sessions` argument (`"bounded"`, `"collapse"`, `"separate"`). Returns edge subsets appropriate for each mode. For `"bounded"`, filters edges to remove cross-session paths. For `"collapse"`, returns all edges ignoring session. For `"separate"`, returns a named list of edge data.frames.

- [ ] **Step 4: Write utils.R — .build_time_bins()**

Takes edge data and interval, returns time bin boundaries. Respects sessions — bins only cover active session periods. Port logic from `ref-temporal_network.R` lines 174-182.

- [ ] **Step 5: Write utils.R — .temporal_bfs()**

Port from `ref-temporal_network.R` lines 297-336. Earliest-arrival temporal BFS. Takes edges (sorted by onset), n_vertices, source, start_time. Returns list of earliest arrival times and predecessor array. This is the core algorithm — the only place a for loop is acceptable.

- [ ] **Step 6: Write utils.R — .temporal_bfs_backward()**

Port from `ref-temporal_network.R` lines 339-358. Reverses edges, negates times, calls `.temporal_bfs()`.

- [ ] **Step 7: Write utils.R — .trace_path()**

Port from `ref-temporal_network.R` lines 437-450. Traces back through predecessor array from target to source.
